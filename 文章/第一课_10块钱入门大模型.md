## 三、第一个程序：让 AI 说"Hello World"

先从最简单的开始。创建一个文件 `hello_ai.py`：

```python
"""
第一个 AI 程序 —— 调用 DeepSeek API
"""
from openai import OpenAI

# 1. 配置 API 客户端
client = OpenAI(
    api_key="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",  # 替换成你的 Key
    base_url="https://api.deepseek.com"               # DeepSeek 的接口地址
)

# 2. 发送第一条消息
response = client.chat.completions.create(
    model="deepseek-v4-flash",                         # 模型名称
    messages=[
        {"role": "system", "content": "你是一个数据工程师的AI助手，说话简洁专业。"},
        {"role": "user", "content": "用一句话介绍什么是大模型？"}
    ]
)

# 3. 打印回复
print(response.choices[0].message.content)
```

打开终端，运行它：

```bash
python hello_ai.py
```

你会看到类似这样的输出：

```
大模型是一种基于海量数据和深度神经网络训练的AI系统，
能够理解并生成自然语言，参数规模通常达到数十亿到数万亿级别。
```

**恭喜！你已经完成了第一次 AI API 调用。** 这 5 行核心代码，就是你通往 AI 世界的第一把钥匙。

### 代码逐行解读（奶妈级）

别急着往下翻，我带你逐行理解这段代码：

**第 1 步：创建客户端**

```python
client = OpenAI(
    api_key="sk-...",              # 你的身份凭证，DeepSeek 用它来计费
    base_url="https://api.deepseek.com"  # 告诉 SDK 把请求发到 DeepSeek 而不是 OpenAI
)
```

这里的 `OpenAI()` 虽然名字叫 OpenAI，但因为我们把 `base_url` 改成了 DeepSeek 的地址，所以实际调用的是 DeepSeek。这是 OpenAI SDK 的一个巧妙设计——**换一个 URL，就能调用不同的大模型。**

**第 2 步：构造消息**

```python
messages=[
    {"role": "system", "content": "你是一个数据工程师的AI助手，说话简洁专业。"},
    {"role": "user", "content": "用一句话介绍什么是大模型？"}
]
```

`messages` 是一个列表，每条消息有两个字段：

- `role`：角色。`system` 是系统指令（定义 AI 的人设），`user` 是用户的问题
- `content`：具体的内容

system 消息非常关键——它决定了 AI 「以什么身份、用什么风格」回答你。后面我们会大量用到它。

**第 3 步：提取回复**

```python
response.choices[0].message.content
```

API 返回的是一个复杂的 JSON 对象，这条语句从中提取出 AI 的回复文本。`choices[0]` 取第一个（通常是唯一一个）候选回复，`.message.content` 取回复的文本内容。

## 四、实战一：让 AI 帮你写 SQL

好了，Hello World 跑通了。接下来我们干点真正有用的——**让 AI 根据自然语言自动生成 SQL**。

作为一个数据工程师，你一定经历过这种场景：业务方丢过来一句话——

> "帮我查一下上个月销售额最高的 10 个商品。"

你脑子里开始转：哪张表？什么字段？要不要 join？日期格式是什么？……

现在，我们让 AI 来做这件事。

```python
"""
实战一：AI 自动生成 SQL
"""
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    base_url="https://api.deepseek.com"
)

# 这是最关键的部分：告诉 AI 你的数据库结构
system_prompt = """
你是一个资深的SQL专家。你需要根据用户的自然语言需求，生成对应的SQL语句。

当前数据库的表结构如下：

-- 订单表
CREATE TABLE orders (
    order_id        BIGINT PRIMARY KEY COMMENT '订单ID',
    product_id      BIGINT COMMENT '商品ID',
    product_name    VARCHAR(200) COMMENT '商品名称',
    category        VARCHAR(50) COMMENT '商品类目',
    sale_amount     DECIMAL(15,2) COMMENT '销售额',
    quantity        INT COMMENT '销售数量',
    order_date      DATE COMMENT '订单日期',
    customer_id     BIGINT COMMENT '客户ID',
    region          VARCHAR(50) COMMENT '地区'
);

-- 客户表
CREATE TABLE customers (
    customer_id     BIGINT PRIMARY KEY COMMENT '客户ID',
    customer_name   VARCHAR(100) COMMENT '客户名称',
    customer_level  VARCHAR(20) COMMENT '客户等级: VIP/Gold/Silver/Normal',
    register_date   DATE COMMENT '注册日期'
);

要求：
1. 只输出SQL语句，不要解释
2. SQL要兼容 MySQL 语法
3. 使用中文别名
4. 注意处理 NULL 值
"""

# 用户的问题
user_question = "帮我查一下上个月销售额最高的10个商品，按销售额降序排列"

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_question}
    ]
)

print("=" * 60)
print("用户提问：", user_question)
print("=" * 60)
print("\nAI 生成的 SQL：\n")
print(response.choices[0].message.content)
```

运行结果：

```
============================================================
用户提问： 帮我查一下上个月销售额最高的10个商品，按销售额降序排列
============================================================

AI 生成的 SQL：

SELECT 
    product_id AS 商品ID,
    product_name AS 商品名称,
    category AS 商品类目,
    SUM(sale_amount) AS 总销售额,
    SUM(quantity) AS 总销量
FROM orders
WHERE order_date >= DATE_FORMAT(DATE_SUB(CURDATE(), INTERVAL 1 MONTH), '%Y-%m-01')
  AND order_date < DATE_FORMAT(CURDATE(), '%Y-%m-01')
GROUP BY product_id, product_name, category
ORDER BY 总销售额 DESC
LIMIT 10;
```

**看到了吗？** AI 不仅生成了正确的 SQL，还自动处理了「上个月」这个相对时间、按销售额汇总、降序排列，甚至主动给字段起了中文别名。

### 核心技巧：System Prompt 是灵魂

这段代码里最值钱的部分，不是 API 调用本身，而是 `system_prompt`。

**一个好的 system prompt 包含三个要素：**

1. **角色定义**：「你是一个资深的 SQL 专家」——这决定了 AI 的知识域和回答风格
2. **上下文信息**：数据库的表结构——这给了 AI 具体的「素材」
3. **输出约束**：「只输出 SQL，不要解释」、「兼容 MySQL 语法」——这控制了输出的格式和质量

你可以把这个 system prompt 保存下来，**以后每次换一张表，只改表结构部分就行。**

## 五、实战二：让 AI 帮你解释 SQL

逆向场景也很常见：接手一个老项目，打开一看，几百行嵌套子查询、各种奇怪的 CASE WHEN……头皮发麻。

现在我们让 AI 来当你的 SQL 翻译官：

```python
"""
实战二：AI 解释复杂 SQL
"""
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    base_url="https://api.deepseek.com"
)

system_prompt = """
你是一个SQL代码解读专家。用户会给你一段SQL，你需要：
1. 用通俗易懂的语言解释这段SQL的业务含义
2. 指出其中的关键逻辑和技巧
3. 如果有性能问题或可优化之处，也请指出

请用「菜鸟也能看懂」的难度来讲解。
"""

# 一段"祖传"SQL（是不是很眼熟？）
complex_sql = """
SELECT 
    a.region,
    a.category,
    a.month_sale,
    a.rank_num,
    b.total_customers,
    ROUND(a.month_sale * 100.0 / SUM(a.month_sale) OVER(PARTITION BY a.region), 2) AS sale_pct
FROM (
    SELECT 
        region,
        category,
        SUM(sale_amount) AS month_sale,
        ROW_NUMBER() OVER(PARTITION BY region ORDER BY SUM(sale_amount) DESC) AS rank_num
    FROM orders
    WHERE order_date >= '2026-07-01' AND order_date < '2026-08-01'
    GROUP BY region, category
) a
LEFT JOIN (
    SELECT 
        region,
        COUNT(DISTINCT customer_id) AS total_customers
    FROM customers c
    INNER JOIN orders o ON c.customer_id = o.customer_id
    WHERE o.order_date >= '2026-07-01' AND o.order_date < '2026-08-01'
      AND c.customer_level IN ('VIP', 'Gold')
    GROUP BY region
) b ON a.region = b.region
WHERE a.rank_num <= 5
ORDER BY a.region, a.rank_num;
"""

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": f"请帮我解读这段SQL：\n\n```sql\n{complex_sql}\n```"}
    ]
)

print(response.choices[0].message.content)
```

运行后，AI 会给你一段类似这样的解读（实际输出会更详细）：

> **业务含义**：这段SQL是用来分析**2026年7月各区域TOP5品类的销售表现**，同时关联了各区域VIP和Gold等级客户的去重数量。
>
> **关键逻辑**：
> 1. 子查询 `a`：按区域和品类汇总7月销售额，并用 `ROW_NUMBER()` 窗口函数对每个区域的品类按销售额排名
> 2. 子查询 `b`：统计每个区域的高价值客户数（VIP+Gold），注意用了 `COUNT(DISTINCT)` 去重
> 3. 主查询：取每个区域的TOP5品类，并计算该品类在所属区域的销售额占比
>

## 六、实战三：搭建一个完整的 SQL 智能助手

前面都是单次调用，现在我们把它组装成一个**可以持续对话的 SQL 助手**。

完整代码：

```python
"""
实战三：SQL 智能助手 —— 支持多轮对话
"""
from openai import OpenAI

# ==================== 配置区 ====================
DEEPSEEK_API_KEY = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # 改这里！

TABLE_SCHEMA = """
-- 订单表 orders
字段: order_id(BIGINT,订单ID), product_id(BIGINT,商品ID), 
      product_name(VARCHAR,商品名称), category(VARCHAR,商品类目),
      sale_amount(DECIMAL,销售额), quantity(INT,销售数量),
      order_date(DATE,订单日期), customer_id(BIGINT,客户ID), 
      region(VARCHAR,地区)

-- 客户表 customers  
字段: customer_id(BIGINT,客户ID), customer_name(VARCHAR,客户名称),
      customer_level(VARCHAR,客户等级:VIP/Gold/Silver/Normal),
      register_date(DATE,注册日期)
"""

SYSTEM_PROMPT = f"""
你是一个SQL智能助手，服务于数据工程师。你的能力包括：

1. 根据自然语言需求生成SQL语句
2. 解释复杂SQL的业务逻辑
3. 提供SQL优化建议

当前可用的数据表：
{TABLE_SCHEMA}

规则：
- 生成SQL时，只输出SQL代码，不要多余解释
- 解释SQL时，用通俗语言，假设读者只有基础SQL知识
- 优化建议要具体，给出改写前后的对比
"""

# ==================== 核心逻辑 ====================
class SQLAssistant:
    def __init__(self):
        self.client = OpenAI(
            api_key=DEEPSEEK_API_KEY,
            base_url="https://api.deepseek.com"
        )
        self.history = [
            {"role": "system", "content": SYSTEM_PROMPT}
        ]

    def chat(self, user_input):
        """发送消息并获取回复"""
        # 将用户输入加入对话历史
        self.history.append({"role": "user", "content": user_input})

        # 调用 API
        response = self.client.chat.completions.create(
            model="deepseek-v4-flash",
            messages=self.history
        )

        # 提取回复
        reply = response.choices[0].message.content

        # 将 AI 回复也加入历史（这样下一轮对话就有上下文了）
        self.history.append({"role": "assistant", "content": reply})

        return reply

    def reset(self):
        """重置对话（保留 system prompt）"""
        self.history = [{"role": "system", "content": SYSTEM_PROMPT}]


# ==================== 交互界面 ====================
def main():
    assistant = SQLAssistant()

    print("=" * 60)
    print("  🚀 SQL 智能助手已就绪")
    print("  输入 'help' 查看示例 | 输入 'reset' 重置对话 | 输入 'quit' 退出")
    print("=" * 60)

    while True:
        try:
            user_input = input("\n🧑 你：").strip()

            if not user_input:
                continue

            if user_input.lower() == 'quit':
                print("\n👋 再见！")
                break

            if user_input.lower() == 'reset':
                assistant.reset()
                print("\n🔄 对话已重置")
                continue

            if user_input.lower() == 'help':
                print("""
    你可以这样问我：

    【写SQL】
    - "查询上个月每个品类的销售额汇总"
    - "找出过去半年内没有下过单的客户"
    - "统计每个地区VIP客户的月均消费金额"

    【解释SQL】
    - "帮我解释这段SQL：[粘贴SQL]"
    - "这段代码的业务含义是什么：[粘贴SQL]"

    【优化SQL】
    - "帮我优化这段SQL：[粘贴SQL]"
    - "这段SQL有没有性能问题：[粘贴SQL]"
                """)
                continue

            # 调用 AI
            print("\n🤖 AI：", end="", flush=True)
            reply = assistant.chat(user_input)
            print(reply)

        except KeyboardInterrupt:
            print("\n\n👋 再见！")
            break
        except Exception as e:
            print(f"\n❌ 出错了：{e}")


if __name__ == "__main__":
    main()
```

保存为 `sql_assistant.py`，运行：

```bash
python sql_assistant.py
```

你会看到一个命令行对话界面：

```
============================================================
  🚀 SQL 智能助手已就绪
  输入 'help' 查看示例 | 输入 'reset' 重置对话 | 输入 'quit' 退出
============================================================

🧑 你：查询上个月每个品类的销售额，按销售额降序

🤖 AI：
SELECT 
    category AS 品类,
    SUM(sale_amount) AS 销售额
FROM orders
WHERE order_date >= DATE_FORMAT(DATE_SUB(CURDATE(), INTERVAL 1 MONTH), '%Y-%m-01')
  AND order_date < DATE_FORMAT(CURDATE(), '%Y-%m-01')
GROUP BY category
ORDER BY 销售额 DESC;

🧑 你：把刚才的SQL改成只要销售额大于10000的品类

🤖 AI：
SELECT 
    category AS 品类,
    SUM(sale_amount) AS 销售额
FROM orders
WHERE order_date >= DATE_FORMAT(DATE_SUB(CURDATE(), INTERVAL 1 MONTH), '%Y-%m-01')
  AND order_date < DATE_FORMAT(CURDATE(), '%Y-%m-01')
GROUP BY category
HAVING SUM(sale_amount) > 10000
ORDER BY 销售额 DESC;
```

注意看第二个回答——AI 记住了上一轮对话的上下文，在原有 SQL 的基础上只加了一个 `HAVING` 条件。这就是 `history` 列表的功劳。

### 代码要点解析

**1. 对话历史管理**

```python
self.history = [
    {"role": "system", "content": SYSTEM_PROMPT}
]
```

`history` 列表保存了所有的对话记录。每次调用 API 时，把完整的历史一起发过去，AI 就能「记住」之前聊过什么。这是实现多轮对话的核心机制。

**2. 每一轮都要追加**

```python
self.history.append({"role": "user", "content": user_input})
# ... 调用 API ...
self.history.append({"role": "assistant", "content": reply})
```

用户说的话和 AI 的回复都要加入历史，缺一不可。如果只加用户的、不加 AI 的，AI 会「失忆」。

**3. Token 消耗提醒**

对话轮次越多，`history` 列表越长，每次请求消耗的 Token 也越多。不过以 DeepSeek 的价格，聊 100 轮也才几分钱，不用太担心。如果确实长了，可以手动调用 `reset()` 清空历史。

## 七、进阶优化：三个让助手更实用的技巧

### 技巧 1：流式输出（打字机效果）

上面的代码是等 AI 全部生成完后一次性输出。改成流式输出，像 ChatGPT 那样一个字一个字往外蹦：

```python
def chat_stream(self, user_input):
    """流式输出版本"""
    self.history.append({"role": "user", "content": user_input})

    stream = self.client.chat.completions.create(
        model="deepseek-v4-flash",
        messages=self.history,
        stream=True  # 开启流式输出
    )

    full_reply = ""
    for chunk in stream:
        if chunk.choices[0].delta.content:
            content = chunk.choices[0].delta.content
            print(content, end="", flush=True)  # 实时打印
            full_reply += content

    self.history.append({"role": "assistant", "content": full_reply})
    print()  # 换行
    return full_reply
```

### 技巧 2：安全地管理 API Key

到现在为止，我们都是把 Key 硬编码在代码里——这在生产环境中是大忌。正确做法是用环境变量：

```bash
# Windows PowerShell
setx DEEPSEEK_API_KEY "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

# Mac / Linux
export DEEPSEEK_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

然后在代码中读取：

```python
import os

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),  # 从环境变量读取
    base_url="https://api.deepseek.com"
)
```

这样你的 Key 就不会泄露到代码仓库里了。

### 技巧 3：错误处理和重试

网络不稳定是常态，加一个重试机制：

```python
import time

def call_with_retry(client, messages, max_retries=3):
    """带重试的 API 调用"""
    for attempt in range(max_retries):
        try:
            response = client.chat.completions.create(
                model="deepseek-v4-flash",
                messages=messages
            )
            return response.choices[0].message.content
        except Exception as e:
            if attempt == max_retries - 1:
                raise  # 最后一次还是失败，抛出异常
            print(f"调用失败，2秒后重试... ({attempt + 1}/{max_retries})")
            time.sleep(2)
```
